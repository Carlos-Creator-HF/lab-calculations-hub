# Lab Calculations Hub

I want to create a website in which I have as the main tittle “Lab” then it  has 2 buttons. The first "Horarios", and the second "Cálculos". button leads to one page in which it could be provide data of X (volume) in mL and y (pressure) in mm of water, then in another window it is asked the atmospheric pressure (Patm) in hPa and the temperature.  Then the page recalculate Z as Z= 1/((9810y/1000)+(Patm100)). Then elaborate a graph of Z vs x,  with a linear fit of the data.  Then represent the data of the linear fit indicating their units as “ams” for the slope and “bms” for the y-intercept. Also, the second, third and fourth button leads to similar pages both the calculation of Z is different in the second page it has the calculation of Z=4y-3. In the third button Z is calculated as Z=(1.15y^2)+(2.35y) +0.135 the last button is calculated as Z=Ln(y). I wants that there is one button on each of this pages in which it is indicated calculate and only provides the data from the linear fit. And another button which indicates generate, which leads to the generation of the graph. Also I want a background green shaded to light blue from the top to the bottom.
